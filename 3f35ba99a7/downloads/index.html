The first time

Opening it the first time

The programs are not signed yet — that needs Microsoft and Apple certificates we don’t have yet — so each system warns you once. It is expected; this is how you get past it. The Read me first in each box tells you the same, for its system.

Windows 11

  1. Right-click the zip → Extract All, and double-click the installer inside. Windows says “Windows protected your PC”.
  2. Click More info → Run anyway.
  3. Choose where to install it, or accept the folder it suggests.

macOS

  1. Double-click the zip: out comes a folder with the app and its English and Castellano folders. Drag the app to Applications.
  2. In Terminal: 
    xattr -cr /Applications/BotFactoryFX.app
  3. On Apple Silicon, if it still won’t open: 
    codesign --force --deep --sign - /Applications/BotFactoryFX.app
  4. If macOS still insists: System Settings → Privacy & Security → Open Anyway.

Linux

  1. Extract the zip: the AppImage comes out ready to run. If it doesn’t open, make it executable (Properties → Allow executing as a program, or chmod +x).
  2. Double-click it. Nothing gets installed.
