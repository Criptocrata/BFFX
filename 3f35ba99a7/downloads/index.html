The first time

Opening it the first time

The programs are not signed yet — that needs Microsoft and Apple certificates we don’t have yet — so each system warns you once. It is expected; this is how you get past it.

Windows 11

  1. Double-click the installer. Windows says “Windows protected your PC”.
  2. Click More info → Run anyway.
  3. Choose where to install it, or accept the folder it suggests.

macOS

  1. Double-click the zip and drag the app to Applications.
  2. In Terminal: 
    xattr -cr /Applications/BotFactoryFX.app
  3. On Apple Silicon, if it still won’t open: 
    codesign --force --deep --sign - /Applications/BotFactoryFX.app
  4. If macOS still insists: System Settings → Privacy & Security → Open Anyway.

Linux

  1. Make the AppImage executable (Properties → Allow executing as a program, or chmod +x).
  2. Double-click it. Nothing gets installed.
