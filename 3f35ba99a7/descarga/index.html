The first time you open it

The program is not signed yet — signing needs Microsoft and Apple certificates we don’t have yet — so each system warns you the first time. That is expected, and you get past it like this (the Read me first in the box says the same):

Windows 11

  1. Right-click the zip → Extract All, and double-click the installer inside. Windows says “Windows protected your PC”.
  2. Click More info → Run anyway.
  3. Choose where to install it, or accept the folder it suggests.

macOS

  1. Double-click the zip: you get a folder with BotFactoryFX.app and the English and Castellano folders. Drag the app to Applications.
  2. Open Terminal (Applications → Utilities) and paste, on one line:
    xattr -cr /Applications/BotFactoryFX.app
    That removes the “downloaded from the internet” mark that makes macOS say the app is damaged.
  3. On Apple Silicon only, if it still won’t open, also paste:
    codesign --force --deep --sign - /Applications/BotFactoryFX.app
    It signs it locally; no account or certificate needed.
  4. If macOS still insists: System Settings → Privacy & Security → Open Anyway.

Linux

  1. Extract the zip: the AppImage comes out ready to run. If it doesn’t open, make it executable: right-click → Properties → Allow executing as a program, or chmod +x on the file.
  2. Double-click it. Nothing gets installed.

For BFQuarantine it is the same, with its own name.
