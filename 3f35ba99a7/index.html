Read this before paying

On Windows and macOS, the first launch is ugly.

Signing a Windows installer and notarising a macOS app cost a few hundred dollars a year and require a registered legal identity. I have not bought either yet, and the honest consequence is that your operating system will not recognise who made this and will say so — loudly. Nothing is wrong with the file. Here is exactly what you will see.

No warning

Linux

An AppImage. Make it executable and run it — chmod +x and a double click. Nothing complains, because nothing on Linux expects a certificate.

Two extra clicks

Windows

SmartScreen shows a blue box reading “Windows protected your PC”. Click More info, then Run anyway. That is the whole of it. The warning is about an unrecognised publisher, not about anything found in the file.

The awkward one

macOS

Gatekeeper refuses it on the first try. On recent versions the old Control-click → Open shortcut no longer works: you have to open System Settings → Privacy & Security, scroll to the message about BotFactoryFX being blocked, and press Open Anyway. It is a detour, and it is the single best reason to run the browser demo first.
